# Concrete Lines

A 3D skateboarding game that runs in the browser: mega ramp, a full-pipe tunnel, a floating bowl, spiral rails, a mini-ramp and more.

**Play:** open the GitHub Pages link for this repo.

**Skate with friends:** one person types a name and presses **Host** to get a code like `SK8-4821`; friends type that code and press **Join**. Then everyone starts a game.

Controls: W push, S brake, A/D carve or spin, Space ollie (hold to crouch), E / Q tricks, R grind or manual, B respawn, N next spot, C camera, P pause, M mute.
